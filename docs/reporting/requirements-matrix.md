Классы проверенного диагностического сценария: Normal, ITSC, RBD. Пять функциональных групп генерации не означают пять валидированных диагностических классов. Исторический сегментный split и разные физические двигатели состояний ограничивают обобщение результатов.

Артефакты испытаний: artifacts/acceptance-2026-09-28 в отчётном checkout; большие файлы остаются вне Git. Копии компактных receipts и итоговый протокол включаются в комплект.

Сравнение по всем девяти бюджетам реальных дефектных окон (2–300), по пяти ResNet: SGDA выше по Accuracy/Macro-F1 во всех парах на проверенных бюджетах до 100; при 200/300 среднее real-trained выше на 0.2608/0.4088 п.п. Общий тест фазы 1 / нагрузки 100% одинаков для всех бюджетов внутри seed. Полная кривая приведена в протоколе. Прежнее сравнение полного режима при бюджете 300 остаётся датированным отдельным результатом.
